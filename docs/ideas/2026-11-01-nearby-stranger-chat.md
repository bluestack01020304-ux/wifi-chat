# 아이디어 메모: 근처의 모르는 사람과 대화하는 앱

상태: **보류(메모만)**. wifi-chat(같은 Wi-Fi 웹 채팅)과는 별개의 새 프로젝트로 본다. 2026-11-01 기획 대화에서 나온 내용을 그대로 남긴다.

## 출발점
- 처음 떠올린 장면: 공공장소(카페 등)에서 같은 Wi-Fi에 접속한 모르는 사람끼리 대화하면 재밌겠다.
- 핵심은 "같은 Wi-Fi"라는 연결 방식이 아니라 **지금 같은 장소에 있는 모르는 사람과 이야기하는 경험**이다.
- wifi-chat이 집·회사 쪽으로 간 이유: 공공 Wi-Fi는 대부분 기기 간 격리(client isolation)로 기기끼리의 직접 연결을 막는다. wifi-chat은 기기 간 직접 연결(WebRTC)이 필수라 공공 Wi-Fi에서는 동작하지 않는다(설계 문서 전제 1).

## 지금까지 기운 방향
- 묶는 기준: **GPS 위치**. Wi-Fi 대신 위치를 쓰고, 메시지는 서버가 중계한다(공공 Wi-Fi 격리와 무관).
- 반경: 사용자마다 허용 반경을 정하고, **서로의 반경 안에 있을 때만** 상대가 보인다(상호 반경).
- 형태: 그룹 채팅방이 아니라 **근처 사람과 1:1 대화**. 목록에서 한 명을 골라 대화를 요청하고, 상대가 수락하면 시작한다.
- 익명 없음: 닉네임으로 보인다.
- 플랫폼: 갤럭시(안드로이드) 앱을 먼저 만든다. 아이폰은 Mac과 Apple 개발자 계정(연 $99)이 필요해서 나중에. 만드는 방식은 React Native(Expo)가 유력하다(Mac 없이 EAS Build로 iOS 빌드 가능).

### 검토했다가 접은 것
- 상호 반경으로 그룹 채팅을 만들면 A–B, B–C는 이어지지만 A–C는 이어지지 않는 문제가 생긴다(그룹 경계가 애매함). 그래서 1:1로 정리했다.
- 대안이었던 묶음 방식: 접속한 Wi-Fi 기준(+서버 중계), 장소 QR, 블루투스 근거리.
- 회사용 보안 채팅, 대화를 영구 보존하는 "디지털 벽화"는 이 아이디어가 아니다.

## 미리 확인된 문제점 (시작 전에 답이 필요함)
1. **위치 노출과 안전**
   - 정확한 거리("약 30m")를 보여 주면 몇 걸음씩 옮겨 다니며 상대 위치를 찾아낼 수 있다(삼변측량).
   - 대응: 거리는 "아주 가까움 / 근처"처럼 뭉뚱그리고, 위치에 일부러 오차를 섞는다.
2. **괴롭힘·스팸·성적 메시지**: 대화 요청과 수락, 차단, 신고, 보내는 횟수 제한이 필요하다. 계정이 없으면 앱을 다시 설치해 차단을 피할 수 있으므로 기기 단위 식별이 필요하다.
3. **법과 정책**
   - 한국에서는 위치정보를 쓰는 서비스에 위치기반서비스사업자 신고가 필요할 수 있다(정확한 요건은 확인 필요).
   - 개인정보 처리방침과 위치정보 이용 동의 화면이 필요하다.
   - Google Play는 사용자끼리 대화하는 앱에 신고·차단 기능과 이용약관을 요구하고, 미성년자 보호 기준도 따져야 한다.
4. **빈 앱 문제**: 주변에 사용자가 없으면 목록이 비어 있고, 그러면 아무도 다시 열지 않는다. 이런 앱에서 가장 흔한 실패 원인이다.
5. **기술**
   - 실내와 지하에서는 GPS가 부정확하다.
   - 백그라운드 위치는 배터리를 많이 쓰고 Play 심사도 까다롭다. 앱을 켜 둔 동안만 위치를 쓰는 것이 현실적이다.
   - 서버가 메시지를 볼 수 있게 할지(아니면 종단 간 암호화), 얼마나 보관할지를 정해야 한다.

## 열린 질문
- 사람들이 이 1:1 대화로 주로 무엇을 하길 기대하는가? 같은 장소에서의 가벼운 질문인지, 새로운 사람 사귀기인지에 따라 안전장치의 수준이 크게 달라진다.

## wifi-chat에서 가져갈 수 있는 것
- 닉네임 생성, 채팅 화면 구성, 서버 운영 경험(Cloudflare Workers + Durable Objects) 정도.
- 기기 간 직접 연결, 호스트 승계, 다리 합치기는 필요 없다. 사실상 새로 만드는 앱이다.
- 덧붙여, wifi-chat을 앱으로 만들 경우 Android 17의 "근처 기기"(로컬 네트워크) 권한을 앱이 직접 요청할 수 있다. 크롬에서는 사용자가 설정에서 직접 켜야 한다(설계 문서 참고).
